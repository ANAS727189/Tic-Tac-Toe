# 🎮 Classic Tic Tac Toe Game 🎲

## 🌟 Overview

Welcome to the Classic Tic Tac Toe Game! This is a simple, fun, and interactive Python implementation of the beloved board game that brings nostalgia and entertainment right to your command line. 

## ✨ Features

- 🕹️ Two-player gameplay
- 📊 Simple, intuitive board representation
- 🏆 Win detection for both X and O players
- 🤝 Easy-to-understand game mechanics

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Command line/terminal

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tic-tac-toe.git
   ```

2. Navigate to the project directory:
   ```bash
   cd tic-tac-toe
   ```

## 🎲 How to Play

1. Run the game:
   ```bash
   python main.py
   ```

2. Players take turns entering a position (0-8) to place their mark:
   ```
   0 | 1 | 2 
   --|---|---
   3 | 4 | 5 
   --|---|---
   6 | 7 | 8 
   ```

3. First player uses 'X', second player uses 'O'

4. Win by getting three of your marks in a row, column, or diagonal

## 🎯 Game Rules

- Each player takes turns marking an empty space
- Cannot overwrite a space already marked
- Game ends when:
  - A player gets three marks in a row (win)
  - All spaces are filled (draw)

## 🤖 Game Variations

Two variations of the game are included:
- `first_version.py`: Basic implementation with simple win checking
- `main.py`: Slightly advanced implementation with state tracking
